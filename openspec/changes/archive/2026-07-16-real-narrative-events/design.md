# Design: real-narrative-events

> 配套 `proposal.md`。时间归属规则的"事件性命题"边界精确化——让带固定历史时间的世界发生在现实语料中有合法落点（历史事实命题），修复文档语料的系统性覆盖丢失。

## Context

- 时间归属规则（b03cda2）为个人记忆语料设计：概念零时间、事实禁相对时间、"带时间的发生归事件层 + MUST NOT 抽事件性命题"。
- 现实 universe 的事件层只装**摄入行为事件**（规则产生）；作品 universe 有 wne 的叙述事件抽取。**现实叙述发生**（新闻里的裁员/判决/赛果）两头都不沾：不是摄入行为、又被禁止抽为命题 → 模型概括丢弃（71KB 裁员清单 222→4 节点取证；A/B 松绑后 67→357 恢复）。
- 既有 spec 本身存在表述张力："事实 MAY 含固定历史时间（如 1976 年）作命题属性" vs "MUST NOT 抽事件性命题"——"Google 于 2023 年 1 月裁员"两条都能套，模型倾向保守合规（丢弃）。

## Goals / Non-Goals

**Goals**
- 消除两条规则的表述冲突：给"带固定历史时间的已完成世界发生"一个明确、可判定的合法落点（历史事实命题）。
- 清单 / 汇总型内容逐条抽取（禁止聚合概括）。
- 保住原规则的本意：用户时间轴不被转述污染、概念零时间、相对/单次时间不进事实 content。

**Non-Goals**
- 不给现实 universe 增加 LLM 叙述事件抽取（D2 评估后否决，留 Phase 2）。
- 不动作品 universe 路径（wne）、不动摄入行为事件、不动概念侧规则。
- 不承诺检索指标提升（子集 A/B 已证抽取恢复；检索收益需全量重建另行验证，非本 change 验收项）。

## 关键设计决策

### D1：边界判据 = 时间形态，不是"是否事件性"

被禁止的"事件性命题"收窄为**以时间形态可判定**的两类：

| 时间形态 | 例 | 落点 |
|---|---|---|
| 相对 / 单次 / 未完成（"今天""这次""计划中"） | "今天去按摩" | 事件层（用户亲历）或去时间化事实 |
| **固定历史时间、已完成** | "2023 年 1 月 Google 裁员 12000 人" | **历史事实命题**（时间留 content）——本 change 解禁 |
| 无时间 | "Google 是搜索公司" | 概念 / 事实（不变） |

- 为什么用时间形态判据：LLM 判"是不是事件性"边界模糊（取证显示它宁可丢弃）；判"时间是固定历史还是相对"形态清晰、与既有"事实 MAY 含固定历史时间"条款自然衔接。
- 灰区处理（"上周谈判破裂"——相对表述的世界发生）：按形态归相对类 → 去时间化事实兜底（"谈判破裂"仍可抽），宁抽勿丢。
- 清单条目：每条一个历史事实 + 涉及实体各自成概念；MUST NOT 卷成聚合概念（A/B TREATMENT 已验证该指令有效）。

### D2：否决"现实叙述事件"（本期）

评估过给现实 universe 加 LLM 叙述事件（`event_meta.kind` 区分摄入 vs 叙述，复用 wne 的 `WorkEventDraft` 机制），本期否决：

- **recall 语义污染风险**：现实事件层当前语义 = 用户亲历时间轴（recall"最近记了什么"）；混入世界新闻事件需要 kind 过滤贯穿 recall / timeline / get_related_events 全链路，改动面大。
- **需求未现**：检索与图质量目标由历史事实命题即可满足（A/B 证实）；"现实世界时间线"的产品需求出现时，再以独立 change 落（届时 kind 分流 + timeline(universe, kind) 扩展，机制现成）。
- **证据经济性**：历史事实路径已被 A/B 验证；叙述事件路径零验证、且多一层 LLM 抽取成本。

### D3：实现 = prompt 措辞 + spec 精确化，零管线结构改动

- `extract_concepts` SYSTEM/USER 的时间归属段按 D1 重写（以 `exp_time_rule_ab.py` 的 TREATMENT prompt 为底稿——已跑过 38 篇文档验证）；作品路径 `extract_work_events` 不动。
- spec / 宪法同步措辞；`WorkEventDraft` / 事件层 / 守门 / 存储零改动。
- 回归锚：A/B 脚本保留；裁员清单文档抽取节点数设下限断言（防措辞回退）。

## 风险与缓解

1. **普通叙事文档过抽**（枚举指令外溢）：A/B 全体 +26%/篇在守门 / dedup 消化范围内；测试覆盖普通短文档抽取量不暴涨。
2. **个人记忆语料回归**（本规则的原始服务对象）：新措辞保留"相对/单次时间禁入"与"概念零时间"，日记场景行为不变——用既有时间归属测试锁定。
3. **prompt override 用户**：`register_prompt` 覆盖过 extract_concepts 的下游不受影响（覆盖优先）。

## 被否决方案

- **全面放开事件性命题**（不设时间形态判据）：会把"今天去按摩"抽成事实、重新污染用户语料——原规则要防的正是这个。
- **现实叙述事件（本期）**：见 D2。
- **bench 层长期 override 而不改核心**：违背"框架层缺陷在框架层修"（framework-vs-bench 分层原则反向应用）——规则冲突在 spec/prompt 本体，override 只是实验工具。
