## 一、宣传定位（魂）

**一句话**：MCS 是一个借鉴人脑认知机制、以语义图为记忆形态的 agent——**图是记忆、agent 在图上游走是思考、硬不变量是基石**。

三层：

| 层 | 是什么 | 对应人脑 |
|---|---|---|
| 记忆形态 | 语义图（反预设本体，结构靠 LLM 涌现） | 联想网络 |
| 思考主体 | agent 在图上游走 | 回忆时从一个念头联想开去 |
| 工程基石 | 硬不变量（任意活跃视图 ≤ T） | 有限工作记忆 |

**向量** = agent 的工具之一（`search.vector` 模式，规划中），不是核心、**不对立于图**。

### 各节详细蓝图

**§0 钩子（~400）**
- 痛点入场：你给 Agent 接的记忆大概率是向量库——多跳/时间/跨文档推理，召回断崖；且向量库是黑盒，LLM 读不懂它召回的东西。
- 抛出：我做了个东西，让 agent 像人一样记忆和思考——记忆是语义图，思考是图上游走。
- 人设埋点：一句话点明"个人开发者、业余时间、穷测"（详细自嘲留 §9）。

**§1 一句话 MCS（~150）**
- MCS（Maximum Context Subgraph）：借鉴人脑认知机制的 agent。把文本组织成 LLM 能直接读的语义图，维持一条硬不变量——任意节点的活跃视图永远装得进一个上下文窗口。
- 返回记忆（节点集），不返回答案；把"说话"留给上层。

**§2 对比表坐标（~500）** —— 详见 §六

**§3 记忆天然是图（~800）**
- 人脑记忆是联想网络，不是 chunk 列表。
- 知识天然有结构：概念关联、事实真伪/互斥、事件时间、来源溯源。
- MCS 的图对应认知：4类节点（概念/事实/事件/source）/ 2类边（关联/互斥）/ 双层（核心图+事件层）/ 多世界 universe。
- [图1：人脑联想网络 vs 向量碎片]

**§4 背景：为什么这么设计（~1000）** —— 详见 §五

**§5 思考主体：agent 游走（~800）**
- 12 个工具 = 12 个认知动作：记(learn)/找(search)/联想(associate)/推理(reason)/回忆(recall)/时间线(timeline)/归纳(generalize)/仲裁(arbitrate)/拆分(split)/合并(merge)/跨世界(get/link_cross_universe)。
- `search → associate → reason` 链 = 人回忆时联想开去。
- **agent vs 框架 = 0.825 vs 0.695**（同图同题）：证明"让 agent 像人一样有方向地读图"碾压"机器式固定遍历"。
- [图3：agent 12 工具链]

**§6 工程基石：硬不变量（~700）**
- 核心奇观：任意节点的活跃双向视图，渲染 token ≤ T（一个上下文窗口）。
- = 模拟人的"有限工作记忆"（同一时刻只能专注一个局部）。
- 怎么维持：守门（改图即把关）+ 聚类裂变（超界主动收敛）。
- 聚类必须 LLM 语义归纳，禁止纯图聚类（铁律二）。
- [图4：节点+活跃视图，标注 token≤T] [图5：裂变 before→after]

**§7 会话自治（~400）**
- `context_budget` 单一硬预算 + 模型自治工作集。
- 存根折叠 / pin / FINISH = 人的遗忘（可逆）、聚焦关键、主动收束。
- 估算口径 == 发送口径（会话层铁律一）。

**§8 两种入口 + demo（~800）** —— Python 库 + MCP 接 Claude，两者并重
- Python 库：`ingest` / `query` 代码示例（开发者可直接复现）。
- MCP 接 Claude Desktop：配置 JSON + 实测对话（"给你的 AI 装个长期记忆"——最有体感）。
- 三后端：DeepSeek / Claude / Ollama（本地零成本）。

**§9 证据（~700）** —— **测评留空，见 §八**

**§10 诚实边界（~400）**
- 测试局限：抽样测试（非全量、非多 seed）、小规模（200/150 题）、单一便宜模型（DeepSeek，未在 GPT-4/Claude 上验证）。大规模 + 多模型 + 稳健性 → 待后续。
- locomo/longmemeval 评测在路上；agent 算法层演进中；系统 Phase 1→2。

**§11 开源 + 召唤（~200）**
- GitHub · MIT · 求 star。
- **召唤贡献者 > 用户**：列具体贡献方向（跑大规模评测、竞品对比、新 universe 场景、插件）。

## 五、§4 反本体论背景章节·详细骨架

> **定位**：反本体论是 MCS 的核心设计立场，但在文里只作**背景/动机**呈现（解释"为什么这么设计"），不上标题、不当主卖点。读者第一眼看"像人一样记忆的 agent"，深读才到这节看设计动机。

```
§4  背景：为什么这么设计 —— 反本体论的工程动机              ~1000字
    [图2: 传统KG(label边+实体类型) vs MCS(无label+结构行为类)]

§4.0 这节聊背景(~150字)
    MCS 为什么不预设领域本体、不预设谓词 label?
    背后是个反本体论的立场——结构靠 LLM 涌现,不靠人工预先定义。

§4.1 三套老办法疼在哪(~500字)  📐 主论证(工程批判)
    ┌─ Prolog/逻辑推理那套 ──────────────────────┐
    │  • 封闭世界假设:没写进规则的=假            │
    │  • 脆性:规则没覆盖的直接崩                  │
    │  • 单调推理:新事实撤不回旧结论,但现实会变  │
    │  • 零学习:知识全靠人工编码                 │
    └──────────────────────────────────────────────┘
    ┌─ 谓词 label 边那套 ─────────────────────────┐
    │  • 谓词类型无限膨胀(born_in/married_to/...) │
    │  • 加一种关系就改全局 schema               │
    │  • 语义硬编码失真(喜欢/崇拜/迷恋本模糊)   │
    │  • 边连不了边 → 事实不能被背书、不能互斥 ★ │
    │  • 查询要先预知有哪些 label 才能遍历        │
    └──────────────────────────────────────────────┘
    ┌─ 预设复杂 schema 那套 ──────────────────────┐
    │  • 设计者要预见一切,但世界开放演化         │
    │  • 领域一变就重做 schema                   │
    │  • schema 是预先切片,切片必漏长尾          │
    │  • schema 与现实漂移,维护跟不上            │
    └──────────────────────────────────────────────┘

§4.2 这不是拍脑袋(~200字)  轻量背书,一段带过
    家族相似(维特根斯坦)·原型理论(罗施)·学界 post-ontology 转向(GraphRAG/A-MEM)
    → 过渡句:"不过比起哲学,我们更在意工程上这几套老办法到底疼在哪。"

§4.3 MCS 的不同做法(~200字)  🔧 3 设计点对位
    ① 节点按结构行为分4类,不预设领域 type(软标签)
    ② 谓词落事实 content,不做 label 边 ← 最强论点(逆转传统 KG 核心抽象)
    ③ 聚类/合并/互斥交 LLM 语义判断,不预设规则

§4.4 代价(~50字)
    MCS 也有最小本体(4类节点/2类边/登记制);LLM 抽取有幻觉,靠护栏兜。
```

**预防式防守（写正文时务必守）**：
- 准确说法是"反预设本体/最小本体+涌现"，不是"无本体"——MCS 自己也有 4类节点/2类边/登记制。
- 专家系统/MT 失败是历史教训，**不能单一归因"用了本体"**；Cyc 失败原因多方面。
- 学界主流是"本体降级为 schema-light 可选层"，不是"本体已死"——别宣称"完胜传统 KG"。
- 与 Mem0/Zep 等同向路线比，强调 MCS 的独特性（无 label 边最彻底 + 硬不变量 + agent 读图），不贬低同行。

## 六、对比表设计

**清单（6 产品 + MCS，分两赛道）**：

```
Document-RAG:  GraphRAG(微软) · LightRAG · Think-on-Graph(ToG,不建图只在现成KG上推理)
Agent Memory:  Mem0 · Zep(Graphiti) · Letta(MemGPT)
─────────────────────────────────────────────────────────────────
MCS: 横跨两赛道(图+agent) · 硬不变量 · 反本体(无label边)
```

**维度**：

| 维度 | 说明 |
|---|---|
| 知识表示 | 向量chunk / 图 / bi-temporal KG / memory blocks / 语义图(无label) |
| **是否预设 schema/label** | 反本体论核心列，MCS 预期全场唯一"否" |
| 建图方式 | 批量(GraphRAG) / 实时增量(Mem0·Zep·MCS) / 不建图(ToG) |
| **模型/成本** ★ | MCS=DeepSeek(便宜)·抽样；竞品多为 GPT-4 级——口径不可直比，但便宜模型到这个数是卖点 |
| **有界性** | 无 / 硬不变量(MCS 独有) |
| LLM 角色 | 检索/抽取/agent 自主游走(MCS) |
| 时间处理 | 无 / bi-temporal(Zep) / 双轨事件层(MCS) |
| LongMemEval | Mem0 ~49% / Zep 63.8-71.2% / MCS 待跑 |
| 形态 | 库 / agent runtime(Letta) / 库+MCP+agent(MCS) |

**位置**：紧跟 §1，作为 §2——读者懂 RAG/agent，先给坐标再讲原理。
